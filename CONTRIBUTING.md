Contributing to Simple Interest Calculator

First of all, thank you for considering contributing to the Simple Interest Calculator project!

Our mission is to empower low-income individuals by making financial calculations simple and accessible.

We welcome contributions from developers and open-source enthusiasts.

How Can You Contribute?

You can contribute by:

Fixing bugs in the Bash script.
Improving the simple interest calculation.
Adding useful features.
Improving documentation.
Improving code readability.
Reporting issues.
Suggesting new ideas.
Getting Started
1. Fork the Repository

Visit the Simple Interest Calculator repository on GitHub and click the Fork button.

This creates your own copy of the repository.

2. Clone Your Fork

Clone your forked repository:

bash
git clone <your-forked-repository-url>


Navigate to the project directory:

bash
cd simple-interest-calculator

3. Create a New Branch

Create a separate branch for your changes:

bash
git checkout -b feature/your-feature-name

4. Make Your Changes

Make the required changes to the Bash script or documentation.

Please ensure that:

Your code is clean and readable.
Your changes are relevant to the project.
Existing functionality is not broken.
5. Test Your Changes

Test the calculator with different principal amounts, interest rates, and time periods.

Make sure the calculations produce the expected results.

6. Commit Your Changes

Stage and commit your changes:

bash
git add .
git commit -m "Improve simple interest calculator"

7. Push Your Changes

Push your branch to your forked repository:

bash
git push origin feature/your-feature-name

8. Create a Pull Request
Open your forked repository on GitHub.
Click Compare & pull request.
Provide a clear description of your changes.
Submit your pull request.
Wait for the project maintainers to review your contribution.
Contribution Guidelines

Please follow these guidelines:

Write clear and understandable code.
Use meaningful commit messages.
Test your changes before submitting a pull request.
Keep pull requests focused on a specific change.
Update documentation when necessary.
Be respectful of other contributors.
Follow our Code of Conduct.
Reporting Bugs

If you discover a bug, create a GitHub issue with:

A clear description of the problem.
Steps to reproduce the issue.
Expected results.
Actual results.
Suggesting Improvements

We welcome suggestions for new features and improvements.

Please create a GitHub issue explaining your idea before starting major changes.

Code of Conduct

All contributors are expected to follow our Code of Conduct.

We are committed to providing a welcoming and inclusive environment for everyone.
