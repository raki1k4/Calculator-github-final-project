Simple Interest Calculator

A simple Bash script to calculate simple interest. This project aims to support financial literacy and empower low-income individuals by providing an easy way to calculate interest.

About the Project

The Simple Interest Calculator is an open-source project developed as part of our initiative to make financial calculations simple and accessible.

It allows users to calculate simple interest based on:

Principal amount
Annual interest rate
Time period
Formula

Simple Interest is calculated using the following formula:

Simple Interest = (Principal × Rate × Time) / 100

Where:

Principal = Initial amount of money.
Rate = Annual interest rate (percentage).
Time = Time period in years.
How to Use
Clone this repository:
bash
git clone <repository-url>

Navigate to the project directory:
bash
cd simple-interest-calculator

Run the Bash script:
bash
bash simple-interest.sh

Enter the principal amount, interest rate, and time when prompted.
Example

Suppose:

Principal = 1000
Rate = 5%
Time = 2 years

Calculation:

Simple Interest = (1000 × 5 × 2) / 100

Result = 100
